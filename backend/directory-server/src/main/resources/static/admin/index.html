Demandes d'enrôlement en attente

Envoyées par les box qui ne sont pas encore enrôlées. Elles se signent sur le poste du responsable, hors ligne : admin enroler-attente --cles organisation.json --codes codes.json --annuaire …. L'outil reconnaît les box à leur code d'enrôlement ; une demande sans code se traite à la main, après comparaison de l'empreinte avec l'installateur.
