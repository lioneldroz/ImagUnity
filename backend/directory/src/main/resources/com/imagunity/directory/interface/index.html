Demandes en attente

Chaque box non enrôlée dépose sa demande dans l'annuaire. Valider signe son entrée ici, sur ce poste, avec la clé de l'organisation, puis la publie. Une demande sans code d'enrôlement ne se valide qu'après avoir comparé son empreinte avec celle que l'installateur lit sur la box.

Organisations partenaires

Pour échanger avec les box d'une autre organisation, chaque responsable reconnaît l'autre : il signe un accord qui fixe la clé du partenaire, ses relais autorisés et les groupes qui peuvent échanger. Un échange ne marche que lorsque les deux responsables ont signé. Sans groupes désignés, aucun échange.
