L’appairage : se présenter une seule fois

1 · Box A

Crée une invitation

Un lien à usage unique, qui expire au bout d’une heure

2 · Hors bande

Transmet le lien

Par un canal de confiance : courriel, téléphone, QR code

3 · Box B

Accepte le lien

Un canal chiffré de bout en bout relie désormais les deux box

Chaque box donne elle-même un nom à son partenaire (« box-b ») : un partenaire ne peut pas se faire passer pour un autre en changeant de nom.

ImagUnity · L’appairage

Avant le premier envoi, les deux box doivent se « présenter », une fois pour toutes. La box A crée un lien d’invitation à usage unique ; un responsable le transmet par un canal de confiance à l’hôpital B ; la box B l’accepte. À partir de là, un canal chiffré de bout en bout existe entre elles. Le nom du partenaire est choisi localement : une box ne peut pas usurper l’identité d’une autre. Pour le pilote, un annuaire signé permettra de vérifier l’empreinte du partenaire et de révoquer un appairage.
