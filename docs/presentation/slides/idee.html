ImagUnity · L’idée

Image à retenir : la box A dépose un colis chiffré dans une boîte aux lettres sur Internet (le relais), la box B vient le retirer. Les deux flèches vont VERS le relais : ce sont deux connexions sortantes. Aucun hôpital n’ouvre de porte vers l’extérieur. Le relais est « aveugle » : il stocke des données chiffrées qu’il ne sait pas lire. Le transport, IU-T, a été conçu pour ImagUnity : le relais sait quelles box échangent et quand, mais il ne voit jamais le contenu des examens.
