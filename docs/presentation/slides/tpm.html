Protection des clés · TPM

Les clés de la box restent dans la box

Chaque box a ses clés secrètes : l’une signe ses messages, l’autre ouvre les examens qu’elle reçoit. Que se passe-t-il si quelqu’un copie son disque ?

Sans TPM : une phrase de passe

Les clés sont chiffrées par une phrase de passe, réservée à l’administrateur, mais rangée sur la même machine.

Une copie complète du disque emporte les deux.

Avec le TPM : une puce de la machine

Le secret qui chiffre les clés est scellé par une puce de sécurité soudée sur la carte mère. Il n’en sort jamais.

Copiés ailleurs, les fichiers de clés ne s’ouvrent pas.

Un disque volé, une sauvegarde égarée ou une machine clonée ne permettent pas de se faire passer pour la box, ni de lire ses examens.

ImagUnity · Clés protégées par le TPM · présent sur la plupart des PC et serveurs récents

Le TPM, pour Trusted Platform Module, est une petite puce de sécurité présente sur presque tous les PC et serveurs récents ; Windows 11 l’exige, par exemple. Elle sait garder un secret sans jamais le laisser sortir : on lui confie le secret, elle le « scelle », c’est-à-dire qu’elle le chiffre avec une clé qui ne quitte jamais la puce. Seul ce TPM, sur cette machine, peut le rendre. Pourquoi c’est utile pour ImagUnity : chaque box possède des clés secrètes, l’une pour signer ses messages, l’autre pour déchiffrer les examens qui lui sont destinés. Sans TPM, ces clés sont chiffrées par une phrase de passe que seul l’administrateur peut lire, mais qui est rangée sur la même machine : une copie complète du disque emporte les clés et leur phrase de passe. Avec le TPM, le secret qui chiffre les clés est scellé dans la puce : un disque volé, une sauvegarde égarée ou une machine clonée ne donnent rien d’utilisable. Une box qui fonctionnait avec une phrase de passe passe au TPM en une fois, au démarrage suivant, sans changer d’identité.
