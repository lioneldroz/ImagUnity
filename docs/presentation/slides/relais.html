ImagUnity · Redondance des relais · campagne de tests, images identiques

Le relais est le seul point commun aux deux hôpitaux ; il ne doit pas devenir un point de panne. Deux façons de s’en protéger, qui se combinent. À gauche, plusieurs relais indépendants, par exemple chez deux hébergeurs différents : chaque box crée une boîte de réception sur chacun, dépose ses messages et ses paquets sur tous, et le destinataire prend ce qu’il trouve. Essai : relais principal arrêté au milieu de l’envoi d’un examen de 300 Mo ; la copie sur le second relais porte l’examen, 600 images sur 600 identiques. À droite, un relais réparti : plusieurs instances du même relais derrière un répartiteur, sur une base et un stockage partagés, déployables sur un petit cluster K3s. Essais : une instance arrêtée pendant le dépôt, puis une mise à jour des instances l’une après l’autre pendant un transfert ; dans les deux cas, 600 images sur 600, sans intervention. Contrepartie des relais multiples : la box envoie les paquets autant de fois qu’il y a de relais ; sur une liaison lente, on peut ne copier les paquets que sur un seul.
