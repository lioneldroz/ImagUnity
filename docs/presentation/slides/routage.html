Jusqu’ici, le PACS choisissait le destinataire : une destination DICOM par hôpital partenaire. Avec le routage, le PACS envoie tout à une seule destination, et c’est la box qui choisit le ou les partenaires d’après le contenu de l’examen : modalité, établissement, description… Les règles sont lues dans l’ordre ; la première qui correspond désigne les destinataires. Essai sur la chaîne de tests : le scanner du CHU part vers l’hôpital B, 10 images sur 10 identiques ; l’IRM part vers deux hôpitaux à la fois ; l’échographie d’une clinique, qu’aucune règle ne couvre, est refusée dès l’envoi par le PACS, qui le signale : rien ne part vers un destinataire non prévu. Les examens déposés par DICOMweb (STOW-RS) passent par les mêmes règles. Les destinations fixes d’avant fonctionnent toujours.
