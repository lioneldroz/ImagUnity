ImagUnity · Réception DICOM

Pour le PACS, la box est un simple destinataire DICOM : l’opérateur envoie l’examen vers la destination « IU_TO_B », et ce nom désigne l’hôpital B. La box n’accepte que les émetteurs déclarés. Les instances (les images) arrivent une à une ; quand plus rien n’arrive pendant 30 secondes, la box considère l’étude comme complète et passe à l’empaquetage. Aucune modification n’est nécessaire côté PACS.
