ImagUnity · Les acteurs

Six acteurs. Les PACS ne changent pas : ils parlent DICOM à la box comme à n’importe quel appareil du service. Chaque box est un petit serveur placé dans l’hôpital, qui contient le logiciel ImagUnity et un client SimpleX non modifié. Sur Internet, deux types de relais : SMP pour les messages courts (annonce d’un envoi, accusé de réception), XFTP pour les fichiers. La console web permet de suivre les transferts ; elle n’est joignable que depuis le réseau de l’hôpital et demande un compte.
